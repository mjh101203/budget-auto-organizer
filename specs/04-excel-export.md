# 04 · 엑셀 출력

위치: `src/export/`. **exceljs**로 브라우저에서 만든다. 양식(레이아웃)은 `src/export/layouts/`에 파일 하나씩 둬서, 학교 양식으로 바꿀 때 그 파일만 고치면 되게 한다.
⚠ 학교 실제 엑셀 양식(`specs/fixtures/school-template.xlsx`)을 구하면 P1에서 그 양식에 맞춘다. 그 전까지는 아래 기본 양식.

## 공통
- 금액 셀은 숫자 타입 + 서식 `#,##0`, 날짜는 `YYYY.MM.DD` 문자열
- 합계 셀은 SUM 수식 + 계산 결과값을 같이 저장 (`{ formula, result }`) → 엑셀에서 열어도, 미리보기에서도 숫자가 보이게
- 표 테두리 thin, 헤더 행 굵게 + 연회색 배경, 글꼴 맑은 고딕 10pt
- 인쇄 설정: A4 가로, 너비 1페이지에 맞춤
- 다운로드 파일명에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 `_`로 바꾼다

## P0 · 구매 품의서 (승인된 요청 1건)
파일명: `품의서_<팀 짧은 이름>_<요청번호>_<승인일 YYYYMMDD>.xlsx` (예: `품의서_R&E3팀_REQ-0004_20261018.xlsx`)
시트 이름: `구매품의서`

```
 1  [A1:I1 병합] 물품 구매 품의서                                   (16pt 굵게, 가운데)
 2  (빈 줄)
 3  요청번호 | REQ-0004        | 요청일 | 2026.10.18 | 예산 구분 | R&E 연구비
 4  팀명     | R&E 3팀 · 토양…  | 요청자 | 김민준     | 지도교사  | 최윤서
 5  용도     | [B5:I5 병합] 토양 수분 자동 관수 시제품 제작
 6  (빈 줄)
 7  연번 | 상품명 | 단품 가격 | 수량 | 총 가격(VAT 포함) | 옵션 | 링크 | 예산 항목 | 비고      ← 헤더
 8~ 품목 행 (연번 1부터). 비고 = 해당 품목의 경고 사유
 n  [A:D 병합] 배송비                         | (E열) 3,000 | (H열) <귀속 항목>
 n+1 [A:D 병합] 합계                          | (E열) =SUM(...) (결과 112,000)
 n+2 (빈 줄)
 n+3 항목별 소계: 재료비 73,400 / 소모품비 38,600   (배송비·부가세 귀속 포함, 0원 항목은 생략)
 n+5 결재 | 담당(학생) 김민준 | 지도교사 최윤서 | 승인일 2026.10.18
```
- 학교 양식 열은 **상품명 · 단품 가격 · 총 가격(VAT 포함) · 옵션 · 링크**. 앞의 연번, 중간의 수량, 뒤의 예산 항목·비고는 우리가 덧붙인 열이다 (⚠ 학교가 싫어하면 `src/export/layouts/`에서 열 하나씩 빼면 된다)
- **단품 가격** = 장바구니에 표시된 단가 그대로. **옵션** = `spec`. **링크** = `url`
- **총 가격(VAT 포함)** = 그 품목의 `amount` + 배분된 부가세. 부가세 배분: 요청의 `vatFee`를 품목 `amount` 비율로 나누고(내림), 남는 원은 금액이 큰 품목부터 1원씩. `vatFee`가 0이면 총 가격 = `amount`
  - 예 (devicemart-3): 17,700+1,770 / 34,000+3,400 / 1,000+100 → 19,470 / 37,400 / 1,100, 합 57,970 + 배송비 2,700 = 60,670 = 결제 예정 금액
- 부가세는 품목별 총 가격에 이미 들어 있으므로 **부가세 줄을 따로 만들지 않는다**. 합계 = 품목 총 가격 합 + 배송비
- 열 너비: 연번 6, 상품명 40, 단품 가격 12, 수량 6, 총 가격 16, 옵션 16, 링크 38, 예산 항목 12, 비고 30. 링크 셀은 하이퍼링크 셀(글자 = URL 그대로, `{text, hyperlink}`)로 만들어 엑셀에서 클릭하면 열리게 한다. 금액 열은 숫자 + `#,##0`

## P1 · 예산 집행 현황 (팀 1개)
파일명: `예산현황_<팀 짧은 이름>_<오늘 YYYYMMDD>.xlsx`
- 시트 `예산현황`: 항목 | 배정액 | 승인 집행액 | 승인 대기 | 잔액 | 집행률(%) — 마지막 행 합계. 집행률 = 승인 집행액 / 배정액, 배정액 0이면 `-`
- 시트 `집행내역`: 승인된 요청의 모든 품목 (요청번호 | 승인일 | 품명 | 수량 | 단가 | 금액 | 예산 항목) + 배송비 행

## P1 · 학교 양식 템플릿 채우기
`specs/fixtures/school-template.xlsx`와 셀 매핑 설명 `specs/fixtures/school-template.md`가 있으면, 기본 양식 대신 템플릿을 열어서 지정된 셀에 값을 채운다. 없으면 이 기능은 만들지 않는다.

## 수용 기준
- 엑셀 생성 함수는 `(state, requestId, now) → Promise<ArrayBuffer>` 순수 함수. 테스트는 만든 버퍼를 exceljs로 다시 읽어서 셀 값·병합 범위·숫자 서식·수식 결과를 확인
- 데모 시나리오의 REQ-0004: 품목 7행, 배송비 3,000, 합계 결과 112,000, 소계 "재료비 73,400 / 소모품비 38,600", 지도교사 최윤서
- 경고 사유가 있는 품목은 비고 열에 사유가 들어간다
- 부가세 배분 단위 테스트: devicemart-2/3 예시 숫자, 나누어떨어지지 않는 경우(예: vatFee 100을 amount 1:1:1로 → 34/33/33), vatFee 0, 품목 합 = 배분 합이 항상 성립
- 모든 품목 행의 상품 링크 셀이 하이퍼링크이고 URL이 입력값과 같다
- 승인 안 된 요청으로 품의서 생성 시도 → 실패 결과 (버튼도 비활성)
- e2e: [품의서 엑셀] 클릭 → 다운로드 이벤트 발생, 파일명이 규칙에 맞음
