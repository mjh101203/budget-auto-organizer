# 예산 자동 정리 시스템

R&E 연구비와 동아리 활동비로 물품을 살 때, **쇼핑몰 장바구니를 붙여넣기만 하면 품목 인식 → 예산 항목 분류 → 규정 검사 → 교사 승인 → 품의서 엑셀**까지 한 번에 처리하는 웹 앱입니다.
Ralphthon(주제: 학교 페인포인트 해결) 출품작이며, 발표자는 문정현입니다.

## 해결하려는 문제

- 학생(R&E 팀장, 동아리 부장)은 구매할 때마다 장바구니의 품명·규격·수량·단가를 학교 품의서 양식에 손으로 옮겨 적고 합계를 직접 계산합니다.
- 비품 기준, 금지 품목, 항목별 잔액 같은 규정은 반려당하면서 배웁니다.
- 지도교사는 단가·수량 오타와 합계 불일치를 매번 다시 검산합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 장바구니 인식 | 디바이스마트·G마켓 장바구니 텍스트(와 HTML)를 붙여넣으면 품목·수량·단가·배송비·부가세를 인식. 할인율 줄(`12% 184,000원`)과 품목 링크도 처리 |
| 인식 실패 보정 | 못 읽은 줄은 원문 그대로 보여주고 [품목으로 추가]로 수동 보정 |
| 자동 분류 | 품명 키워드로 예산 항목(재료비, 소모품비, 물품구입비 등) 자동 분류, 사용자가 바꾼 항목은 유지 |
| 규정 검사 | 항목별 잔액 초과(오류), 비품 의심 고가 품목·금지 품목(경고), 배송비·부가세 배분 안내. 오류가 있으면 제출 차단 |
| 예산 맞추기 제안 | 잔액을 넘으면 어떤 품목 수량을 줄이면 맞는지 추천 |
| 교사 승인 | 승인 대기 목록, 승인 또는 사유를 적은 반려, 처리 이력, 팀별 집행률 막대 |
| 품의서 엑셀 | 승인된 요청을 학교 양식 열(상품명, 단품 가격, 총 가격(VAT 포함), 옵션, 링크)에 맞춰 내려받기 |
| 예산 집행 현황 엑셀 | 팀별 예산현황·집행내역 시트 |
| 요청 복제 | 지난번 주문을 다시 담기 |
| 인쇄용 화면 | Ctrl+P → A4 가로 |

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5173
```

- 백엔드 없이 동작하고 데이터는 브라우저 `localStorage`(`yesan:v1`)에 저장됩니다. 화면 아래 [데모 초기화]로 시드 데이터로 되돌릴 수 있습니다.
- 상단 선택 상자에서 역할(학생 김민준 · R&E 3팀, 교사 최윤서 등)을 바꿔가며 쓸 수 있습니다. 인물과 팀은 모두 가상입니다.

## 3분 데모 시나리오

데모 장바구니는 `specs/fixtures/carts/demo-cart.txt`입니다. 같은 장바구니의 HTML 버전은 `demo-cart.html`이고, 텍스트와 HTML을 한 번에 붙여넣으면 품목 링크까지 채워집니다.

1. 학생 **김민준 (R&E 3팀)** 로 시작합니다. 홈의 재료비 잔액은 **317,700원**입니다.
2. [새 구매 요청] → 데모 장바구니 붙여넣기 → [인식]. 품목 8개, 배송비 3,000원, 합계 **441,000원**으로 인식됩니다.
3. 규정 검사에서 "재료비 잔액 초과" 오류와 "비품 의심" 경고가 나오고 [제출]이 막힙니다.
4. 고가 품목(오실로스코프)을 삭제하면 합계가 **112,000원**, 이번 요청 후 재료비 잔액이 **244,300원**이 됩니다. 용도를 입력하고 제출하면 요청번호 `REQ-0004`가 생깁니다.
5. 역할을 **교사 최윤서**로 바꿔 승인 대기 목록에서 승인합니다.
6. 학생으로 돌아와 상태가 **승인**인 것을 확인하고 [품의서 엑셀]을 내려받습니다.

이 시나리오 전체가 `e2e/demo.spec.ts`로 자동 검증됩니다.

## 기술 스택

Vite · React 19 · TypeScript(strict) · Tailwind CSS · exceljs · Vitest · Playwright

## 프로젝트 구조

```
src/domain/parser/   장바구니 파서 (쇼핑몰별 어댑터, 정규화, 링크 추출)
src/domain/          분류, 규정 검사, 잔액 계산, 수량 줄이기 제안, 승인 흐름
src/config/          예산 항목, 분류 키워드, 규정 수치 (규정 값은 이 파일 한 곳에서만 바꿉니다)
src/export/          품의서·예산현황 엑셀 생성
src/ui/, src/store/  화면과 localStorage 저장소
specs/               기능 명세와 실제 장바구니 fixture (정답 JSON 포함)
e2e/                 Playwright 데모 시나리오
```

## 검증

```bash
npm run check   # 타입 검사 → 린트 → 단위 테스트 → 빌드 → e2e
```

`specs/fixtures/carts/real/`의 실제 장바구니는 사람이 확인한 정답 JSON과 짝으로 있고, 파서 테스트가 자동으로 모두 돌립니다.

## 만든 방식

사람이 `specs/`에 기능 명세를 쓰고, Claude Code를 반복 실행하는 루프(Ralph loop)가 작업 하나씩 구현하고 `npm run check`가 통과해야 커밋하도록 했습니다. 막히면 실행 중에 지시를 넣어 방향을 바꿨습니다. 루프 도구 설명은 [HARNESS.md](HARNESS.md), iteration별 기록은 `PROGRESS.md`에 있습니다.

## 알려진 한계

- 예산 한도, 비품 의심 기준, 금지 품목은 **가정값**입니다. 학교 지침이 정해지면 `src/config/`만 고치면 됩니다.
- 품의서 엑셀은 학교 양식의 열 구성을 가정해 만든 것으로, 실제 제출용 템플릿 연동은 다음 단계입니다.
- 지원하는 쇼핑몰은 디바이스마트와 G마켓이고, 엘레파츠·쿠팡 등은 아직 없습니다.
- 장바구니를 텍스트만 붙여넣으면 품목 링크가 비어 있을 수 있습니다. HTML 서식이 같이 복사되어야 상품 주소가 채워집니다.
- 로그인과 데이터 저장은 데모용입니다. 서버가 없고 데이터는 브라우저에만 남습니다.
